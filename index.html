tiger-bridge

Static redirector that bridges https:// URLs to the Tiger Trade custom URL scheme so Telegram (which only renders http/https hrefs as clickable) can deep-link into the iOS/Android Tiger app at a specific stock.

Usage

>

→ serves 404.html (per GitHub Pages convention) → JS reads
AAPL from the path → window.location.replace("tigerbrokers://stockDetail?symbol=AAPL&market=US").



Editing


If Tiger changes the custom scheme, edit SCHEME_TEMPLATE at
the top of the <script> in 404.html — the
redirector handles every symbol via the URL path, so no per-symbol files
need updating.
